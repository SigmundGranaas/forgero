# Forgero

Build tools from parts. A diamond pickaxe head on an oak handle with a leather binding.

## What This Mod Does

- Craft tool parts separately (heads, handles, blades, guards)
- Combine parts to make tools
- Mix materials - iron head with oak handle, diamond blade with netherite guard
- Add upgrades like gems, reinforcements, and grips
- Adds hundreds of new craftable items

## How It Works

**Regular Minecraft:**
```
Diamond + Diamond + Stick = Diamond Pickaxe
```

**Forgero:**
```
1. Craft a diamond pickaxe head
2. Craft a handle (or use a stick)
3. Combine them to make a pickaxe
4. Optionally add a binding, gems, or reinforcements
```

## Tool Parts

**Pickaxe/Axe/Shovel/Hoe:**
- Head (determines main stats)
- Handle (affects durability and speed)
- Binding (optional grip upgrade)

**Sword:**
- Blade (determines damage)
- Handle
- Guard (optional)
- Pommel (optional)

**Armor:**
- Plate (main protection)
- Lining (optional comfort layer)
- Reinforcement (optional extra protection)

## Materials

Any material can be used for any part:
- Wood, Stone, Iron, Gold, Diamond, Netherite
- Copper, Amethyst, Bone, Obsidian
- And more from content packs

## Schematics

Better schematics give better stats but cost more materials:
- Standard - Normal stats
- Refined - Better stats, costs more
- Mastercrafted - Best stats, costs the most

## The Crafting Station

A special workbench for:
- Assembling parts into tools
- Adding and removing upgrades
- Taking tools apart

## Content Packs

Forgero is modular. Install what you want:

- `forgero-base` - Pickaxe, axe, shovel, hoe, sword
- `forgero-extended-weapons` - Daggers, spears, maces, katanas
- `forgero-armor` - Armor pieces
- `forgero-gems` - Gem upgrades
- `forgero-mining` - Hammer, excavator tools

## Installation

Requires Fabric Loader and Fabric API for Minecraft 1.20.1.

## Forgero vs Vanilla Upgrades

**Forgero**: New crafting system. Build tools from parts. Hundreds of new items.

**Vanilla Upgrades**: Just adds upgrade slots to existing vanilla tools. No new items, no new crafting.

Pick Forgero if you want the full experience. Pick Vanilla Upgrades if you just want to add a few upgrades to your regular tools.
